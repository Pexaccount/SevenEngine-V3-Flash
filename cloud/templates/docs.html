SevenEngine 云扫描 API

通过 HTTP 调用 PE 静态检测：上传二进制文件，返回恶意分。Base URL 即当前主机；除特别说明外所有端点返回 JSON，且全部响应带 Access-Control-Allow-Origin: *，浏览器可直接跨域调用。

服务状态

GET/api/health存活检查 + 引擎元数据

返回模型是否加载成功，以及特征维度、判定阈值与进程运行时长。可放心轮询，同时作为 Render 健康检查路径。

{
  "ok": true,
  "engine": "SevenEngine V3 Flash",
  "feature_dim": 940,
  "threshold": 99,
  "uptime_sec": 189
}
GET/api/stats累计统计

当前进程的累计数据：扫描总数、各分类数量、平均推理耗时与哈希缓存条目数。

{
  "ok": true,
  "total": 7,
  "malware": 2,
  "clean": 5,
  "error": 0,
  "avg_ms": 86.4,
  "cache_size": 6,
  "uptime_sec": 48
}
GET/api/history最近扫描记录

按时间倒序返回最近扫描记录。环形缓冲最多 500 条，进程重启后清空。

参数类型说明
limitint, query返回条数，默认 100，最大 500。
 
{
  "ok": true,
  "count": 3,
  "items": [
    { "name": "ProcessFilter_1.sys", "status": "clean", "score": 30,
      "size": 137120, "ms": 17, "time": "2026-11-01 16:47:48" }
  ]
}

扫描接口

POST/api/scan主接口，multipart 上传

以 multipart 表单上传单个二进制文件，字段名 file。引擎按 MZ 魔数识别 PE、忽略扩展名，提取 940 维特征并评分。单请求最大 300 MB；可选字段 threshold 可在 1-100 间自定义判定阈值，省略时用默认值 99。

字段类型说明
filebinaryPE 样本，最大 300 MB。
thresholdint, form可选。1-100，默认 99；指定自定义阈值时结果不写入缓存。
 
# curl
curl -F "file=@sample.exe" https://your-host/api/scan
{
  "ok": true,
  "name": "notepad.exe",
  "size": 360448,
  "status": "clean",
  "label": "Clean",
  "score": 0,
  "threshold": 99,
  "ms": 26,
  "md5": "971b133d2119877b5631e4a33f1ed4bf",
  "sha256": "002b2ec6d7210b0c354d56192bd429657f9990ea8535fc4b7f5350c02483f3eb"
}

Re-uploading a sample whose SHA-256 is already cached skips inference and returns immediately with "cached": true.

StatusCodeMeaning
400JSONMissing or empty file field.
413JSONPayload exceeds 300 MB.
POST/api/scan/textplain text, SevenEngine native format

Same input as /api/scan, but the body is the engine's native two-line text protocol. Handy for drop-in replacement of the local CLI in existing pipelines. The classification is also mirrored in the X-SevenEngine-Status response header.

Return:ML:Gen.Malware
Score:94
Return:ML:Clean
Score:0
# not a PE file
Return:Error
Score:None
POST/api/scan/base64JSON 提交，无需 multipart

适合不便使用 multipart 的客户端：用 JSON 传 base64 字符串。解码后最大 300 MB。

字段类型说明
namestring可选样本名，原样回显。
datastringbase64 编码的文件内容。
 
{
  "name": "sample.bin",
  "data": "TVqQAAMAAAAEAAAA..."
}
POST/api/scan/hash按哈希查询，无需上传

用 SHA-256 或 MD5 查询已扫描样本。命中时返回缓存判定，未命中返回 "found": false，需重新上传文件。

字段类型说明
sha256string64 位十六进制，优先使用。
md5string32 位十六进制，可作为备选。
 
# cache hit
{ "ok": true, "lookup": "cache-hit", "status": "clean", "score": 0 }
# never seen
{ "ok": true, "lookup": "unknown", "found": false }

判定语义

模型输出 0-100 的恶意分。默认判定阈值 99，可通过 /api/scan 的 threshold 字段在 1-100 间自定义。

分数状态解读
>= threshold（默认 99）malware达到阈值，判为恶意。
< thresholdclean低于阈值，未发现强恶意特征。
nullerror非 PE 文件、空文件或解析失败。
特征提取每文件最多采样 2 MB 原始字节，300 MB 安装包与小型 DLL 的推理速度接近；文件仍会整体哈希用于缓存标识。官方交流群：777353898
