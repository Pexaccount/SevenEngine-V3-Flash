API Reference

Checking

SevenEngine Cloud API

Static PE detection over HTTP. Upload a binary, receive a maliciousness score. Base URL is this host; every endpoint answers with JSON unless noted, and all responses carry Access-Control-Allow-Origin: * so browser clients can call the API directly.

Service Status

GET/api/healthliveness + engine metadata

Reports whether the model is loaded, plus the feature dimension, decision threshold and process uptime. Safe to poll. Also used as the Render health check path.

{
  "ok": true,
  "engine": "SevenEngine V3 Flash",
  "feature_dim": 1086,
  "threshold": 85,
  "uptime_sec": 189
}
GET/api/statsaggregate counters

Running totals for this worker process: how many samples were scanned, how they were classified, the mean inference time, and how many hashes are currently cached.

{
  "ok": true,
  "total": 7,
  "malware": 2,
  "clean": 5,
  "error": 0,
  "avg_ms": 86.4,
  "cache_size": 6,
  "uptime_sec": 48
}
GET/api/historyrecent scan records

Newest-first list of the last scans. Ring buffer of 500 entries, reset when the worker restarts.

ParamTypeDescription
limitint, queryHow many records to return. Default 100, maximum 500.
 
{
  "ok": true,
  "count": 3,
  "items": [
    { "name": "ProcessFilter_1.sys", "status": "clean", "score": 30,
      "size": 137120, "ms": 17, "time": "2026-11-01 16:47:48" }
  ]
}

Scanning

POST/api/scanprimary endpoint, multipart upload

Send one binary as multipart form data with the field name file. The engine reads the MZ magic, ignores the filename extension, extracts 1086 features and scores the sample. Maximum 300 MB per request.

FieldTypeDescription
filebinaryThe PE sample. Anything up to 300 MB.
 
# curl
curl -F "file=@sample.exe" https://your-host/api/scan
{
  "ok": true,
  "name": "notepad.exe",
  "size": 360448,
  "status": "clean",
  "label": "Clean",
  "score": 0,
  "ms": 26,
  "md5": "971b133d2119877b5631e4a33f1ed4bf",
  "sha256": "002b2ec6d7210b0c354d56192bd429657f9990ea8535fc4b7f5350c02483f3eb"
}

Re-uploading a sample whose SHA-256 is already cached skips inference and returns immediately with "cached": true.

StatusCodeMeaning
400JSONMissing or empty file field.
413JSONPayload exceeds 300 MB.
POST/api/scan/textplain text, SevenEngine native format

Same input as /api/scan, but the body is the engine's native two-line text protocol. Handy for drop-in replacement of the local CLI in existing pipelines. The classification is also mirrored in the X-SevenEngine-Status response header.

Return:ML:Gen.Malware
Score:94
Return:ML:Clean
Score:0
# not a PE file
Return:Error
Score:None
POST/api/scan/base64JSON body, no multipart

For clients where multipart is awkward: send the sample as a base64 string inside JSON. Maximum decoded size is 300 MB.

FieldTypeDescription
namestringOptional label for the sample, echoed back.
datastringBase64-encoded file content.
 
{
  "name": "sample.bin",
  "data": "TVqQAAMAAAAEAAAA..."
}
POST/api/scan/hashverdict by hash, no upload

Look up a previously scanned sample by SHA-256 or MD5. Returns the cached verdict when this worker has seen the hash, otherwise "found": false with a hint to upload the file.

FieldTypeDescription
sha256string64 hex characters. Preferred.
md5string32 hex characters. Accepted as fallback.
 
# cache hit
{ "ok": true, "lookup": "cache-hit", "status": "clean", "score": 0 }
# never seen
{ "ok": true, "lookup": "unknown", "found": false }

Verdict Semantics

The model emits a maliciousness score from 0 to 100. The decision boundary is fixed at 85.

ScoreStatusInterpretation
85 - 100malwareAbove threshold, treat as malicious.
0 - 84cleanBelow threshold, no strong malicious pattern.
nullerrorNot a PE image, empty file, or unreadable.
Feature extraction samples at most 2 MB of raw bytes per file, so a 300 MB installer is scored as fast as a small DLL. The whole file is still hashed for cache identity.
