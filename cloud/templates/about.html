Feature Extraction Pipeline

Every uploaded sample is parsed as a PE image. The engine never trusts the file extension; it reads the DOS header magic MZ and walks the full structure.

ParseDOS header, PE header, optional header, 16 section table entries.
StatisticsByte histogram, 128-chunk entropy / mean / diversity map.
StructuresSection attributes, data directories, Rich header, export / resource tables.
ImportsTop-10 sensitive API hits, DLL / function name histograms, string signals.
ScoreLightGBM booster outputs 0-100 maliciousness, threshold 85.
